# CDF website redesign concept

An independent, unofficial website redesign prototype by SystemON for the Cooperative Development Foundation. Visit [cdf.coop](https://www.cdf.coop/) for the official website.

The preview includes Home, About, Programs, Impact, News, Resources, Get Involved, Careers, and a browser-local Editor Demo. The site uses static HTML, CSS, and JavaScript.

## Publishing

GitHub Pages publishes this project from `main` and `/(root)`.
